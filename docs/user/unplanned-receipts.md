# Ungeplanten Wareneingang erfassen

Unter **Wareneingang → Wareneingänge** können Lieferungen ohne vorhandene Bestellung oder Avis angenommen werden.

1. **Ungeplanten Eingang erfassen** wählen.
2. Wareneingangsnummer, Lieferant und optional die Lieferscheinnummer erfassen.
3. Artikel, Annahmeplatz, Menge und gegebenenfalls Charge oder Seriennummer auswählen.
4. Mit **Annehmen** speichern. Zu diesem Zeitpunkt entsteht noch kein Bestand.
5. Den Eingang prüfen und anschließend mit **In Bestand buchen** abschließen.

Die Buchung kann nur einmal erfolgen. Seriennummern sind auf eine Einheit je Position begrenzt. Für beschädigte oder prüfpflichtige Ware kann bereits bei der Annahme ein gesperrter Bestandsstatus gewählt werden.
