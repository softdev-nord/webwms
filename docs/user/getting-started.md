# WebWMS 3.0 Grundlagen

WebWMS 3.0 wird schrittweise neben den bisherigen Funktionen aufgebaut.
Mandanten trennen Organisationen und ihre Daten voneinander. Innerhalb eines
Mandanten können mehrere Lagerstandorte, Benutzer und Rollen bestehen.

Für die neuen Funktionen gelten folgende Grundsätze:

- Datensätze werden nicht zwischen Mandanten geteilt.
- Deaktivieren erhält Historie und Zuordnungen.
- Eindeutige Codes vereinfachen Scan-, Import- und Integrationsprozesse.
- Bestandsänderungen werden künftig vollständig im Bestandsjournal geführt.

Die verfügbaren Funktionen hängen von den Rollen und Rechten des angemeldeten
Benutzers ab.
