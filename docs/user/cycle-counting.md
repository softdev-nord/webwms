# Permanente und Nulldurchgangsinventur verwenden

## Permanente Inventur planen

Ein Zählplan legt fest, welcher Lagerbereich in welchem Abstand gezählt wird. Dazu werden Lager, Lagerplatzpräfix, Intervall und erster Fälligkeitstermin erfasst. Sobald der Termin erreicht ist, kann aus dem Plan eine Zählung gestartet werden.

Nach dem Start zeigt das System den nächsten Fälligkeitstermin an. Für denselben Lagerbereich kann nicht gleichzeitig eine weitere offene Inventur angelegt werden.

## Nullbestände kontrollieren

Wird die letzte Einheit eines Bestands entnommen oder umgelagert, erzeugt das System automatisch eine Kontrollzählung. Kontrolliert wird genau der betroffene Artikel mit seinen Chargen-, Seriennummern-, MHD- und Statusmerkmalen am ursprünglichen Lagerplatz.

Offene Kontrollen werden nicht doppelt erzeugt. Die auslösende Bestandsbewegung bleibt am Inventurbeleg nachvollziehbar.

## Zählung abschließen

Die Bearbeitung entspricht einer Stichtagsinventur:

1. tatsächliche Menge eintragen;
2. Zählung einreichen;
3. Differenzen durch eine andere berechtigte Person prüfen und freigeben;
4. das System erzeugt erforderliche Korrekturbuchungen.

Bei einer Nullbestandskontrolle bestätigt die Zählmenge `0`, dass der Lagerplatz tatsächlich leer ist. Wird noch Bestand gefunden, entsteht eine prüfpflichtige Differenz.
