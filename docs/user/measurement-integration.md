# Waagen und Volumenmessung verwenden

Der Arbeitsbereich **Integration & Technik → Waagen und Volumenmessung** zeigt alle Messgeräte und die zuletzt verarbeiteten Messungen.

## Messgerät anlegen

1. **Messgerät anlegen** öffnen.
2. Code und Namen vergeben.
3. Als Typ **Waage**, **Volumenmessung** oder **Kombigerät** auswählen.
4. Das Gerät aktivieren und speichern.

Pausierte Geräte können keine neuen Messungen liefern.

## Messung verarbeiten

1. **Messung erfassen** öffnen und ein aktives Gerät wählen.
2. Zieltyp **Paket** oder **Artikel** sowie die Ziel-ID auswählen.
3. Gewicht in Gramm und/oder alle drei Abmessungen in Millimetern eintragen.
4. Die Messung als akzeptiert oder abgelehnt kennzeichnen.

Eine akzeptierte Messung wird direkt auf das Ziel übernommen. Pakete lassen sich nur messen, solange der zugehörige Packauftrag offen ist. Abgelehnte Messungen verändern keine Stammdaten, bleiben aber mit Benutzer, Zeitpunkt und Prüfhinweis nachvollziehbar. Wiederholte Requests mit derselben Request-ID erzeugen keinen zweiten Journaleintrag.
