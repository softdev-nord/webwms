# Abweichungen im Wareneingang bearbeiten

Beim Annehmen eines geplanten Wareneingangs tragen Sie die tatsächlich gezählte Menge ein. Entspricht sie nicht der avisierten Menge, ist zusätzlich ein Abweichungsgrund erforderlich.

1. Erfassen Sie die **Ist-Menge** und den Grund der Unter- oder Überlieferung.
2. Führen Sie die QS aus. Eine offene Mengenabweichung wird zwingend in den Sperrbestand gebucht.
3. Prüfen Sie die hervorgehobene Soll-/Ist-Abweichung.
4. Wählen Sie **Freigeben**, um den Sperrbestand in verfügbaren Bestand umzubuchen, oder **Ablehnen**, damit die Ware gesperrt bleibt.
5. Erfassen Sie zu jeder Entscheidung einen nachvollziehbaren Grund.

Freigegebene Ware kann anschließend regulär zur Einlagerung geplant werden. Abgelehnte Ware bleibt für Einlagerungsaufträge gesperrt.
