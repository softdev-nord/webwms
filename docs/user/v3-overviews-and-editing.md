# Übersichten, Anlegen und Bearbeiten

Die Verwaltungsseiten sind in drei klare Arbeitsschritte getrennt:

1. Die **Übersicht** zeigt vorhandene Einträge und bietet Suche, Filter, Sortierung und Paginierung.
2. Über **Anlegen** öffnen Sie eine eigene Erfassungsseite.
3. Über **Bearbeiten** in der jeweiligen Tabellenzeile öffnen Sie eine eigene Seite für Änderungen.

Unter **Lager & Bestand** stehen für die Lagertopologie und Sperrgründe zusätzliche Untermenüpunkte bereit. In der Lagertopologie wählen Sie über **Anlegen**, ob ein Standort, Lager, Bereich, Gang oder Lagerplatz erzeugt werden soll.

Bei Sonderbeständen und Bestandssperren führt die Aktion in der Bestandszeile ebenfalls auf eine separate Seite. Prüf- und Freigabeaktionen einer Bestandssperre befinden sich zusammen mit dem Journal auf ihrer Bearbeitungsseite.
