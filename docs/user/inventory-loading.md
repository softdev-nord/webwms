# Sendungen verladen

## Manifest anlegen

Legen Sie für eine Tour und ein Fahrzeug ein Manifest an und wählen Sie die
etikettierten Sendungen aus. Nicht etikettierte oder bereits einem Manifest
zugeordnete Sendungen werden abgewiesen.

## Ladeliste bearbeiten

Bestätigen Sie jede physisch verladene Sendung einzeln, idealerweise nach dem
Scan der Trackingnummer. WebWMS zeigt anhand der Anzahl geladener und gesamter
Sendungen den Fortschritt. Eine Bestätigung kann nicht doppelt gebucht werden.

## Manifest abschließen

Schließen Sie das Manifest erst nach der vollständigen Ladekontrolle ab.
WebWMS verhindert den Abschluss bei offenen Positionen. Beim Abschluss werden
alle Sendungen gemeinsam auf **versendet** gesetzt und Benutzer sowie Zeitpunkt
der Übergabe protokolliert.

## Korrekturen

Dieser Slice unterstützt noch kein Öffnen oder Stornieren abgeschlossener
Manifeste. Fehler müssen deshalb vor dem Abschluss der Ladeliste korrigiert
werden.
