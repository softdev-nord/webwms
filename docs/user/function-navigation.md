# Funktionen im Menü finden

Die Navigation zeigt ausschließlich Funktionen, für die der angemeldete Benutzer eine Berechtigung besitzt. Bereiche mit mehreren Funktionen lassen sich über den Pfeil im Hauptmenü aufklappen.

## Übersichten und Bearbeitung

Jeder Funktionsbereich besitzt eine eigene Übersicht. Vorhandene Datensätze werden dort tabellarisch angezeigt. Mit **Bearbeiten** wird die separate Detail- oder Bearbeitungsseite geöffnet.

Anlage- und Erfassungsseiten, die keinen vorher ausgewählten Datensatz benötigen, sind als eingerückte Untermenüpunkte erreichbar. Dazu gehören beispielsweise neue Wareneingänge, Ausgangsaufträge, Benutzer, Rollen, Schnittstellen, Geräte und Druckaufträge.

## Funktionsparität

Der Menübereich **Funktionsparität** enthält:

- eine Gesamtübersicht,
- einzelne Übersichten für alle Konfigurationsarten,
- einzelne Übersichten für alle operativen Prozessarten.

Auf einer Konfigurationsübersicht kann mit **Anlegen** ein neuer Eintrag erstellt werden. In der Tabelle führt **Bearbeiten** auf eine separate Formularseite. Auf einer Prozessübersicht startet **Vorgang starten** einen neuen Vorgang; vorhandene Vorgänge werden über **Bearbeiten** geöffnet und entsprechend der zulässigen Statuswechsel fortgeführt.

Fehlt ein Menüpunkt, obwohl die Funktion benötigt wird, muss die zugehörige Rolle um die angezeigte Lese-, Schreib- oder Ausführungsberechtigung erweitert werden.
