## Einordnung nach Definition of Done

Keines der 96 Tickets war zu diesem Zeitpunkt vollständig `Done`. Die Tickets verlangen neben dem fachlichen Backendkern eine bedienbare API oder Oberfläche, konkrete Berechtigungsprüfungen, Auditierung sowie vollständige Erfolgs-, Fehler- und Grenzfalltests.

Die bisherigen Slices konzentrierten sich auf Domainmodell, Application Handler, DBAL-Persistenz, Migrationen, Unit-Tests und Dokumentation. Deshalb wird zwischen `Backend umgesetzt`, `Teilweise umgesetzt` und `Done` unterschieden.
